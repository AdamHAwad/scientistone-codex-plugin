# Support

Use [GitHub Issues](https://github.com/AdamHAwad/scientistone-codex-plugin/issues) for repeatable bugs, install problems, missing docs, and feature proposals. Remove private datasets, project paths, credentials, unpublished results, and other sensitive material before posting.

Include the plugin version, Codex app, expected behavior, observed behavior, smallest safe reproduction, and any non-sensitive log or verifier output. State whether the problem also occurs in a fresh task or clean checkout.

Use the private process in [SECURITY.md](SECURITY.md) for vulnerabilities.
