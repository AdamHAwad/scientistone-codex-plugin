# Attributions

## ScientistOne paper and Chain of Evidence

This repository adapts ideas, workflow language, and file concepts from *ScientistOne: Towards Human-Level Autonomous Research via Chain-of-Evidence* by Rui Meng, Bhavana Dalvi Mishra, Jiefeng Chen, Chun-Liang Li, Palash Goyal, Mihir Parmar, Yiwen Song, Yale Song, Rajarishi Sinha, Parthasarathy Ranganathan, Burak Gokturk, Jinsung Yoon, and Tomas Pfister, arXiv:2605.26340v1, 2026. The paper uses [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/).

These repository images adapt explanatory work based on the paper:

- `docs/images/from-question-to-completed-study.png`
- `docs/images/how-a-result-is-checked.png`

They have been modified for this Codex project. They do not show that the plugin reproduces the paper's tested system or scores.

## Public generated artifacts

The paper's authors publish evaluated papers and solution code at <https://github.com/scientist-one/generated-artifacts> under Apache-2.0. We reviewed commit `721f1fbe3b39a558dff13386c50621a357e6f9a7` for provenance. Version 1.1.0 of this repository does not copy that solution code. The link is here so readers can inspect the research artifacts that accompany the paper.

The release bundle includes ScientistOne's Codex-native local browser and monitor. It does not include `@tintinweb/pi-subagents` or the deprecated predecessor harness.
