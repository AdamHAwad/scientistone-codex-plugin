# Scientist1 Protocols.io package

This folder contains a ready-to-enter beginner protocol for Scientist1.

## Files

- `scientist1-beginner-protocol.md`: the full protocol text.
- `scientist1-beginner-protocol.docx`: an editable upload and review copy.
- `protocols-io-field-map.md`: where each part belongs in the Protocols.io editor.
- `LICENSES.md`: licenses and image credits for the public protocol.
- `example-data/bean-seedling-growth.csv`: the small practice dataset.
- `example-data/README.md`: data meaning, expected values, and CC0 terms.
- `assets/`: the images used in the protocol.
- `qa/`: reading-level, content, accessibility, and reviewer reports.

## What to enter or upload

Build the public guide in the Protocols.io editor with the Markdown source and the field map. The DOCX is an editable review copy. Do not assume that Protocols.io will import its layout.

Enter or upload these items:

- Copy the title, description, warnings, sections, steps, expected result, and references from the Markdown source.
- Upload `assets/00-thumbnail.png` as the thumbnail.
- Upload the PNG files listed under `Image placement` in the field map.
- Attach `example-data/bean-seedling-growth.csv` as the practice file.
- Copy the CSV's CC0 notice from `example-data/README.md` into the file description.
- Select CC BY 4.0 for the protocol text and copy the needed credits from `LICENSES.md`.

Keep the `qa` folder, this README, the field map, and the DOCX as working files. They do not need to be public protocol attachments.

Nothing in this folder has been uploaded or published by the build process.
